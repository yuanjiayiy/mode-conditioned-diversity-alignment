## How It Works

```
Your Config (YAML)
    ↓
main_ppo.py reads config
    ↓
reward.py::get_custom_reward_fn() loads your file
    ↓
Your function is wrapped with reward_kwargs
    ↓
Passed to RayPPOTrainer
    ↓
Called on every batch during training
    ↓
Your function processes DataProto
    ↓
Returns rewards → Updates policy
```

## Customizing the Reward Function

The provided `custom_reward_function.py` includes three components:

### 1. Math Reward (`compute_math_reward`)
- Extracts answers from `\boxed{...}` or `#### ...` format
- Compares with ground truth
- Returns 1.0 for correct, 0.0 for wrong

**Customize:**
```python
def compute_math_reward(response: str, ground_truth: str = None) -> float:
    # Add your custom math checking logic
    # E.g., handle fractions, equations, multiple answers
    pass
```

### 2. Text Quality Reward (`compute_text_quality_reward`)
- Checks length (50-500 words)
- Checks sentence structure
- Measures repetitiveness

**Customize:**
```python
def compute_text_quality_reward(response: str, prompt: str = None) -> float:
    # Add your custom quality metrics
    # E.g., grammar checking, relevance scoring, coherence
    pass
```

### 3. Distinctiveness Reward (`compute_distinctiveness_reward`)
- Compares n-gram overlap between responses
- Penalizes repetitive generations
- Encourages diversity

**Customize:**
```python
def compute_distinctiveness_reward(
    response: str, 
    all_responses_in_batch: List[str],
    weight: float = 0.3
) -> float:
    # Add your custom diversity metrics
    # E.g., semantic similarity, entropy-based measures
    pass
```

### 4. Main Function (`hybrid_reward_function`)
Orchestrates all three components based on `data_source`.

**Customize:**
```python
if data_source == 'code':
    # Add code-specific reward logic
    reward = compute_code_reward(response, test_cases)
elif data_source == 'creative_writing':
    # Add creative writing metrics
    reward = compute_creativity_reward(response)
```

## Advanced Customization Examples

### Example 1: Add External API Call

```python
import requests

def call_external_judge(prompt: str, response: str) -> float:
    """Call external API for reward scoring."""
    api_response = requests.post(
        "https://your-api.com/score",
        json={"prompt": prompt, "response": response}
    )
    return api_response.json()["score"]

def hybrid_reward_function(data: DataProto, **kwargs):
    # Use external API for some examples
    for i, item in enumerate(data.batch):
        if item.get('use_external_judge', False):
            reward = call_external_judge(item['prompt'], item['response'])
```

### Example 2: Multi-Aspect Scoring

```python
def compute_multi_aspect_reward(response: str) -> Dict[str, float]:
    """Score multiple aspects of response."""
    return {
        'accuracy': compute_accuracy(response),
        'fluency': compute_fluency(response),
        'relevance': compute_relevance(response),
        'creativity': compute_creativity(response),
    }

def hybrid_reward_function(data: DataProto, aspect_weights=None, **kwargs):
    if aspect_weights is None:
        aspect_weights = {
            'accuracy': 0.4,
            'fluency': 0.3,
            'relevance': 0.2,
            'creativity': 0.1,
        }
    
    for i, item in enumerate(data.batch):
        aspects = compute_multi_aspect_reward(item['response'])
        rewards[i] = sum(
            aspects[aspect] * weight 
            for aspect, weight in aspect_weights.items()
        )
```

### Example 3: Task-Specific Weights

```python
def hybrid_reward_function(data: DataProto, **kwargs):
    # Define weights per task type
    task_configs = {
        'math': {'math_weight': 1.0, 'text_weight': 0.0, 'distinct_weight': 0.1},

        'code': {'math_weight': 0.5, 'text_weight': 0.3, 'distinct_weight': 0.2},
    }
    
    for i, item in enumerate(data.batch):
        task_type = item.get('data_source', 'text')
        config = task_configs.get(task_type, task_configs['text'])
        
        # Apply task-specific weights
        rewards[i] = (
            config['math_weight'] * math_reward +
            config['text_weight'] * text_reward +
            config['distinct_weight'] * distinct_reward
        )
```

## Passing Custom Parameters via Config

You can pass any parameters to your function via `reward_kwargs`:

```yaml
custom_reward_function:
  path: "/path/to/custom_reward_function.py"
  name: "hybrid_reward_function"
  reward_kwargs:
    math_weight: 1.0
    text_weight: 0.8
    distinctiveness_weight: 0.3
    # Add custom parameters:
    use_external_api: true
    api_url: "https://my-api.com/score"
    temperature: 0.7
    min_length: 50
    max_length: 500
    custom_threshold: 0.85
```

```python

    **kwargs

        # Use the parameters
        pass
```
